Capability reference¶

This is a historical, source-pinned assessment. Its classifications predate later successor implementations. Use Diagnostic’s maintained Empyrical migration guide for current routes and release requirements; the counts below do not establish current coverage or a complete-replacement recommendation.

This reference covers 82 capabilities. Thirty-nine have partial destination coverage and 43 have no verified equivalent. Aliases and small public helpers are included; the counts do not measure the proportion of a user’s analytical workload. No capability is marked complete without its relevant API, numerical and workflow contracts being qualified.

Source and test links are pinned. Test links identify navigation targets; they do not assert that every linked test was executed in this assessment. The recorded numerical comparison contains 169 shared-input cases, of which 143 match values and shapes within rtol=1e-10 and atol=1e-12, including equal NaNs. An equal case does not establish complete contract coverage.

Use Migrating selected metrics for the runnable columnwise recipe. This page is a lookup reference, not a replacement implementation. The machine-readable coverage retains the same classification and precise source/test links. The shared-input numerical evidence records inputs, package versions, pinned source fingerprints and every result.
